# 🧪 Тестирование Hexapod

## Быстрый запуск тестов

**Windows:**
```bash
run_tests.bat
```

**Linux/Mac:**
```bash
chmod +x run_tests.sh  # только первый раз
./run_tests.sh
```

## Структура

```
📦 hexapod/
├── 🕷️ hexapod.ino          # Основной код (Arduino IDE)
├── ⚙️ config.h            # Конфигурация
├── 📡 commands.h          # Команды
├── 🧪 run_tests.bat       # Запуск тестов (Windows)
├── 🧪 run_tests.sh        # Запуск тестов (Linux/Mac)
└── 📁 tests/              # Система тестирования
    ├── test_framework.h
    ├── test_hexapod.cpp
    ├── run_tests.cpp
    └── ... (другие файлы тестов)
```

## ⚠️ Важно

- **Arduino IDE НЕ компилирует файлы из папки `tests/`**
- **Тесты запускаются отдельно на ПК**
- **Всегда запускайте тесты перед загрузкой на ESP32**

## 🎯 Цель

Система тестирования проверяет логику трипоидной походки и безопасность команд **ДО** загрузки на железо, что экономит время и предотвращает ошибки.

Подробная документация: `tests/TEST_SYSTEM_README.md`
