# 🕷️ Hexapod Testing System

Система для тестирования логики гексапода перед загрузкой на ESP32.

## 🎯 Назначение

Эта система позволяет:
- ✅ Тестировать алгоритмы трипоидной походки на ПК
- ✅ Проверять безопасные пределы сервоприводов  
- ✅ Валидировать команды и конфигурацию
- ✅ Отлаживать инверсию левых ног
- ✅ Симулировать движения без реального железа

## 🧪 Типы тестов

### 1. Тесты конфигурации
- `servo_mapping_valid` - Валидность каналов сервоприводов (1-32)
- `leg_offsets_reasonable` - Разумные калибровочные смещения
- `lift_directions_valid` - Корректность инверсии левых ног

### 2. Тесты безопасности  
- `pulse_constraints` - Ограничения PWM сигналов (1000-2000μs)
- `invalid_servo_channels` - Обработка невалидных каналов

### 3. Тесты трипоидной походки
- `tripod_groups_correct` - Правильность групп ног
- `gait_pulse_ranges` - Безопасность значений в походке
- `left_leg_inversion` - **КРИТИЧЕСКИЙ** - Инверсия левых ног

### 4. Тесты команд
- `commands_initialization` - Инициализация контроллера
- `reset_all_servos` - Сброс в стартовые позиции

### 5. Тесты траекторий
- `trajectory_values_safe` - Безопасность значений траекторий
- `trajectory_progression` - Логика движения

## 🕷️ Интеграция с основным кодом

### Синхронизация изменений
1. Внесите изменения в основные файлы (`hexapod.ino`, `config.h`, и т.д.)
2. **ОБЯЗАТЕЛЬНО** синхронизируйте изменения в соответствующих test_*.h файлах
3. Запустите тесты: `./test.sh` или `test.bat`
4. Если все тесты прошли ✅ - загружайте на ESP32
5. Если есть ошибки ❌ - исправьте перед загрузкой

### Критические тесты
Особенно важны тесты:
- `left_leg_inversion` - проверяет, что левые ноги поднимаются правильно
- `gait_pulse_ranges` - гарантирует безопасность движений
- `tripod_groups_correct` - правильность алгоритма походки

## 💡 Советы по использованию

### Перед каждой загрузкой на ESP32
```bash
# Быстрый тест всей системы
./test.sh  # или test.bat

# Если тесты прошли - загружайте на ESP32
# Если нет - исправляйте ошибки
```

### При разработке новых функций
1. Добавьте тест для новой функции
2. Запустите тесты - они должны FAIL
3. Реализуйте функцию  
4. Запустите тесты - теперь они должны PASS
5. Загружайте на ESP32

### При отладке проблем с походкой
1. Запустите `left_leg_inversion` тест
2. Изучите вывод позиций сервоприводов
3. Исправьте логику инверсии
4. Повторите до успеха

## ⚠️ Важные замечания

- **НЕ редактируйте** test_*.h файлы без соответствующих изменений в основном коде
- **ВСЕГДА запускайте тесты** перед загрузкой на ESP32
- **Особое внимание** уделяйте тестам инверсии левых ног
- Система тестирования **НЕ заменяет** реальное тестирование на железе
