## ✨ Что было добавлено

### 1️⃣ Расширенное управление движением

#### **BWD (Назад)**
```cpp
case MovementDirection::BACKWARD:
  coxa_direction *= -1;  // Инверсия всех ног
```
- **Файл:** `hexapod.ino`
- **Строки:** 198-201
- **Метод:** Инверсия направления COXA через `movement_direction`

#### **LEFT (Поворот влево)**
```cpp
case MovementDirection::TURN_LEFT:

```
- **Файл:** `hexapod.ino`
- **Строки:** 203-208
- **Эффект:** Поворот против часовой стрелки

#### **RIGHT (Поворот вправо)**
```cpp
case MovementDirection::TURN_RIGHT:
  if (!is_left_leg) coxa_direction *= -1;  // Правые ноги назад
```
- **Файл:** `hexapod.ino`
- **Строки:** 210-215
- **Эффект:** Поворот по часовой стрелке

### 2️⃣ Жесты и анимации

#### **SHAKE (Пожатие лапы)**
- **Функция:** `perform_shake_gesture()`
- **Строки:** 244-280
- **Нога:** Front Right (leg 0)
- **Последовательность:**
  1. Поднять ногу (coxa +80, femur +200, tibia -150)
  2. Тряска 3 раза (tibia -200 ↔ -100)
  3. Возврат в neutral

#### **WAVE (Махание)**
- **Функция:** `perform_wave_gesture()`
- **Строки:** 282-315
- **Нога:** Front Right (leg 0)
- **Последовательность:**
  1. Поднять ногу (femur +150, tibia +150)
  2. Махание 3 раза (coxa +100 ↔ -100)
  3. Возврат в neutral

### 3️⃣ Регулировки позы тела

#### **BODY_UP / BODY_DOWN**
- **Функция:** `adjust_body_height(±50)`
- **Строки:** 321-339
- **Действие:** Изменяет FEMUR и TIBIA всех 6 ног
- **Эффект:** Поднятие/опускание корпуса

#### **HEAD_UP / HEAD_DOWN**
- **Функция:** `adjust_head_tilt(±50)`
- **Строки:** 341-363
- **Действие:** Передние ноги вверх/вниз, задние обратно
- **Эффект:** Наклон корпуса вперёд/назад

#### **LEAN_LEFT / LEAN_RIGHT**
- **Функция:** `adjust_body_lean(±50)`
- **Строки:** 365-386
- **Действие:** Левые ноги вверх/вниз, правые обратно
- **Эффект:** Наклон влево/вправо

#### **TWIST_LEFT / TWIST_RIGHT**
- **Функция:** `adjust_body_twist(±50)`
- **Строки:** 388-402
- **Действие:** Все COXA поворачиваются в одном направлении
- **Эффект:** Скручивание корпуса

## 🔧 Технические детали

### Архитектурные изменения

#### Enum MovementDirection
```cpp
enum class MovementDirection {
  STOP,
  FORWARD,
  BACKWARD,
  TURN_LEFT,
  TURN_RIGHT
};
```

#### Модифицированная handle_gait_cycle()
**Добавлен switch для направлений:**
```cpp
switch (movement_direction) {
  case MovementDirection::BACKWARD:
    coxa_direction *= -1;
    break;
  case MovementDirection::TURN_LEFT:
    if (is_left_leg) coxa_direction *= -1;
    break;
  case MovementDirection::TURN_RIGHT:
    if (!is_left_leg) coxa_direction *= -1;
    break;
  case MovementDirection::FORWARD:
  default:
    break;
}
```

### ✅ По сравнению с Legacy:

| **Архитектура** | Блокирующая | Неблокирующая |

## 🚀 Рекомендации по использованию

### Первый запуск:
```bash
1. Загрузите hexapod.ino на ESP32
2. Откройте Serial Monitor (115200 baud)
3. Подключитесь к WiFi или AP "Hexapod_Config"
4. Откройте веб-интерфейс (192.168.4.1 или IP робота)
5. Выполните RESET → DIAGNOSTIC → FWD
```

## 📝 Не реализованные функции (и почему)

### ❌ Claw_Open / Claw_Close
**Причина:** В текущем дизайне робота нет клешни (claw). Это дополнительный аксессуар, который можно добавить позже.

### ✅ Pos_SRV() → RESET
**Заменено:** Команда `RESET` выполняет ту же функцию.

### ✅ Pos_INT() → STOP
**Заменено:** Команда `STOP` возвращает робота в нейтральную позицию.

### ✅ Speed Walk/Run → SLOW/FAST/NORMAL
**Улучшено:** Вместо двух скоростей (Walk/Run) реализованы три режима с переключением на лету.
