# ⚡ Быстрое решение проблемы 0.03V

## 🚨 Проблема
Индикатор батареи показывает **0.03V** вместо реального напряжения (~11-12V).

## 🔍 Причина
ADC читает почти нулевое напряжение (raw ≈ 10 из 4095), что означает:
- Делитель напряжения не подключен, или
- Неправильный пин, или  
- Обрыв в соединении

## ✅ Быстрое решение (выберите вариант)

### Вариант 1: Подключить делитель напряжения (если ещё не подключён)

```
Батарея+ ----[ 100kΩ ]----+----[ 33kΩ ]---- GND
                           |
                       GPIO1 (A0)
```

**Где взять резисторы:**
- 100 кОм: коричневый-чёрный-жёлтый (или коричневый-чёрный-чёрный-оранжевый)
- 33 кОм: оранжевый-оранжевый-оранжевый

### Вариант 2: Используйте тестовый режим (без батареи)

Замените функцию в `hexapod.ino`:

```cpp
float read_battery_voltage() {
  return 11.5f;  // Возвращает фиксированное значение для теста
}
```

Загрузите код → индикатор покажет 11.5V.

### Вариант 3: Измените коэффициент (если резисторы другие)

В `config.h` пересчитайте:

```cpp
// Если у вас другие резисторы:
constexpr float VOLTAGE_DIVIDER = (R1 + R2) / R2;

// Примеры:
// R1=100k, R2=33k → 4.03
// R1=100k, R2=30k → 4.33
// R1=220k, R2=68k → 4.24
```

## 🧪 Диагностика (3 минуты)

1. **Загрузите обновлённый код** (уже содержит диагностику)
2. **Откройте веб-интерфейс**
3. **Нажмите кнопку "🔋 Battery Check"** (новая кнопка рядом с Joint Directions)
4. **Откройте Serial Monitor** (115200 baud)

Вы увидите:
```

```

### Анализ результата:

| ADC raw | Диагноз | Решение |
|---------|---------|---------|
| 0-50 | Делитель не подключен | Подключите резисторы |
| 50-500 | Неправильный коэффициент | Измените VOLTAGE_DIVIDER |
| 500-1500 | Низкая батарея | Зарядите батарею |
| 1500-3000 | ✅ Нормально | Всё работает |

## 🔧 Если нет резисторов прямо сейчас

### Временное решение - симуляция:

В `hexapod.ino` замените функцию `read_battery_voltage()`:

```cpp
float read_battery_voltage() {
  // СИМУЛЯЦИЯ: возвращаем реалистичное значение
  // Позже замените на реальное чтение
  static float simulated_voltage = 11.8f;
  
  // Медленная разрядка для реализма (0.01V каждые 5 минут)
  simulated_voltage -= 0.00033f;
  if (simulated_voltage < 9.0f) simulated_voltage = 12.0f; // Перезарядка
  
  Logger::log(Logger::INFO, "Battery (simulated): %.2fV", simulated_voltage);
  return simulated_voltage;
}
```

Это покажет **симулированный** уровень заряда пока вы не подключите реальный делитель.
