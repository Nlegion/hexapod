## 📊 Технические характеристики

### Точность измерений:
- **Разрешение ADC**: 12-bit (4096 уровней)
- **Точность напряжения**: ±0.05V (при калибровке)
- **Усреднение**: 10 измерений для стабильности
- **Частота обновления**: 0.2 Hz (каждые 5 секунд)

### Производительность:
- **Время чтения ADC**: ~1 мс
- **Нагрузка на CPU**: минимальная (<0.1%)
- **Трафик WebSocket**: ~15 байт каждые 5 секунд
- **Память**: +200 байт RAM, +2 KB Flash

## 🚀 Следующие шаги

### Для начала работы:

1. **Подключите делитель напряжения**:
   ```
   Батарея+ → R1(100kΩ) → ADC_PIN (A0) → R2(33kΩ) → GND
   ```

2. **Настройте коэффициент** в `config.h`:
   ```cpp
   constexpr float VOLTAGE_DIVIDER = 4.03f; // (100+33)/33
   ```

3. **Загрузите код** на ESP32-S3

4. **Проверьте** в Serial Monitor:
   ```
   [INFO] Battery monitor initialized on pin A0
   [INFO] Battery status sent: 11.45V
   ```

5. **Откройте веб-интерфейс** - индикатор должен отображаться в header

### Для калибровки:

1. Измерьте реальное напряжение мультиметром
2. Сравните с показаниями на веб-странице
3. Скорректируйте `VOLTAGE_DIVIDER` по формуле:
   ```
   VOLTAGE_DIVIDER_new = VOLTAGE_DIVIDER_old × (V_real / V_displayed)
   ```

### Опционально:

- Настройте пороги предупреждений под свою батарею
- Измените интервал обновления (по умолчанию 5 сек)
- Добавьте звуковое предупреждение при низком заряде
- Интегрируйте с системой безопасности (auto-stop при критическом уровне)
