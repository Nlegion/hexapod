## 🚀 Быстрый старт

### 1. Загрузка на ESP32:
```bash
Arduino IDE → Открыть hexapod.ino → Upload
```

### 2. Первоначальное тестирование:
```
Команда → Ожидаемый результат
──────────────────────────────
RESET   → Нейтральная поза
SHAKE   → Выразительное пожатие правой ногой
WAVE    → Выразительное махание ЛЕВОЙ ногой
FWD     → Прямое движение вперёд (проверить отклонение < 5°)
BWD     → Прямое движение назад
LEFT    → Поворот влево
RIGHT   → Поворот вправо
```

### 3. Измерение прямолинейности:
```
1. Поставить робота на ровной поверхности
2. Отметить начальную позицию
3. Команда: FWD (SLOW режим)
4. Дать роботу пройти 1 метр
5. Измерить отклонение от прямой линии
   Ожидаемое: < 5° (было ~15-20°)
```

## 📐 Техническая информация

### Траектории TRANSFER (нога в воздухе):
```cpp
Шаг 0: {1320, 1700, 1250}  // Старт из задней позиции
Шаг 1: {1500, 1800, 1150}  // Нейтраль + максимальный подъём
Шаг 2: {1680, 1800, 1150}  // Максимально вперёд
Шаг 3: {1680, 1550, 1450}  // Опускание
```

### Траектории SUPPORT (нога на земле):
```cpp
Шаг 0: {1680, 1550, 1450}  // Начало из передней позиции
Шаг 1: {1600, 1520, 1480}  // Толчок назад
Шаг 2: {1450, 1490, 1510}  // Продолжение толчка
Шаг 3: {1320, 1470, 1530}  // Максимально назад (мощный толчок)
```

### Симметрия:
```
TRANSFER начало (1320) = SUPPORT конец (1320) ✅
TRANSFER конец (1680) = SUPPORT начало (1680) ✅
```

## 🔧 Устранение неполадок

### Проблема: Робот всё ещё движется не прямо
**Решение:**
1. Проверьте калибровку: `CALIBRATE`
2. Проверьте механику: нет ли перекосов ног
3. Проверьте поверхность: должна быть ровной
4. Используйте `JOINT_TEST` для проверки направлений

### Проблема: Ноги задевают землю при переносе
**Решение:**
1. Проверьте FEMUR подъём (должен быть +300)
2. Проверьте TIBIA подъём (должен быть -350)
3. Возможно нужна дополнительная калибровка высоты

### Проблема: Жесты не выполняются
**Решение:**
1. Проверьте что робот не в режиме движения (нажмите `STOP`)
2. Проверьте батарею (должно быть > 11V)
3. Проверьте Serial Monitor на наличие ошибок
