# 🕷️ Отчёт: Исправление траекторий и жестов (версия 3.0)

## 📅 Дата: 2025-10-03

## 🎯 Проблемы, выявленные пользователем:

1. ❌ **Робот движется не прямо**, а немного боком
2. ❌ **Амплитуда движений недостаточна** для заметного перемещения
3. ❌ **Жесты SHAKE и WAVE неяркие**, мало заметны

---

## 🔍 Анализ проблем

### 1. Недостаточная амплитуда COXA

**Проблема:**
```cpp
// Старая версия (2.0):
constexpr int TRANSFER_TRAJ[4][3] = {
  {1400, 1680, 1280},  // COXA диапазон: 1400-1600 (±100)
  {1500, 1750, 1200},
  {1600, 1750, 1200},
  {1600, 1500, 1500}
};
```

**Амплитуда COXA:** всего ±100 (200 единиц общий размах)
- Это слишком мало для заметного движения
- MG90 сервопривод может обеспечить ±180 безопасно

**Симптомы:**
- Робот движется очень медленно
- Шаги короткие и недостаточные
- Отклонение от прямолинейности из-за малой тяги

## ✅ Решения

### 1. Увеличение амплитуды COXA (±100 → ±180)

#### Новые траектории (версия 3.0):

```cpp
constexpr int TRANSFER_TRAJ[4][3] = {
  // Фаза ПЕРЕНОСА: нога поднимается и выносится вперёд
  {1320, 1700, 1250},  // COXA=-180 (МАКСИМАЛЬНО НАЗАД!)
  {1500, 1800, 1150},  // COXA=0 (нейтраль)
  {1680, 1800, 1150},  // COXA=+180 (МАКСИМАЛЬНО ВПЕРЁД!)
  {1680, 1550, 1450}   // COXA=+180 (готовимся к опоре)
};

constexpr int SUPPORT_TRAJ[4][3] = {
  // Фаза ОПОРЫ: нога толкает назад, двигая тело вперёд
  {1680, 1550, 1450},  // COXA=+180 (начало из передней позиции)
  {1600, 1520, 1480},  // COXA=+100
  {1450, 1490, 1510},  // COXA=-50
  {1320, 1470, 1530}   // COXA=-180 (МАКСИМАЛЬНО НАЗАД! - мощный толчок)
};
```

#### Улучшения:
- ✅ **Амплитуда увеличена на 80%:** ±100 → ±180
- ✅ **Полная симметрия:** TRANSFER начинается где SUPPORT заканчивается
- ✅ **Циклическая непрерывность:** 1320 → 1500 → 1680 → 1680 → 1600 → 1450 → 1320
- ✅ **Больший подъём:** FEMUR +300 (было +250), TIBIA -350 (было -250)

### 2. Улучшенные жесты

#### SHAKE (пожатие лапы) - версия 3.0

```cpp
void perform_shake_gesture() {
  // Шаг 1: Поднять ногу высоко и вынести вперёд
  SafetySystem::set_servo(coxa_servo, coxa_neutral + 150);   // Вперёд
  SafetySystem::set_servo(femur_servo, femur_neutral + 250); // Высоко
  SafetySystem::set_servo(tibia_servo, tibia_neutral - 250); // Выпрямить
  delay(400);
  
  // Шаг 2: "Пожатие" - быстрые движения FEMUR вверх-вниз (4 раза!)
  for (int i = 0; i < 4; i++) {
    SafetySystem::set_servo(femur_servo, femur_neutral + 300);
    SafetySystem::set_servo(tibia_servo, tibia_neutral - 200);
    delay(120);
    SafetySystem::set_servo(femur_servo, femur_neutral + 200);
    SafetySystem::set_servo(tibia_servo, tibia_neutral - 300);
    delay(120);
  }
  
  // Шаг 3: Медленно вернуть ногу в нейтраль
}
```

**Улучшения:**
- ✅ **Большая амплитуда:** +150/+250 (было +80/+200)
- ✅ **Больше повторений:** 4 раза (было 3)
- ✅ **Используется ВСЯ нога:** COXA + FEMUR + TIBIA
- ✅ **Плавный возврат:** Постепенное опускание

---

#### WAVE (махание) - версия 3.0

```cpp
void perform_wave_gesture() {
  // Используем ЛЕВУЮ переднюю ногу - лучше видно!
  int leg = LEG_FRONT_LEFT;
  
  // Шаг 1: Поднять ногу МАКСИМАЛЬНО высоко
  SafetySystem::set_servo(femur_servo, femur_neutral + 300);  // Очень высоко!
  SafetySystem::set_servo(tibia_servo, tibia_neutral + 250);  // Подогнуть
  delay(400);
  
  // Шаг 2: Махание COXA с БОЛЬШОЙ амплитудой (4 раза!)
  for (int i = 0; i < 4; i++) {
    SafetySystem::set_servo(coxa_servo, coxa_neutral - 200); // Наружу
    delay(180);
    SafetySystem::set_servo(coxa_servo, coxa_neutral + 150); // Вовнутрь
    delay(180);
  }
  
  // Шаг 3: Вернуть в нейтраль
}
```

**Улучшения:**
- ✅ **Использует ЛЕВУЮ ногу:** Лучше видна спереди
- ✅ **Максимальный подъём:** +300 (было +150)
- ✅ **Большая амплитуда махания:** -200 до +150 (было ±100)
- ✅ **Больше повторений:** 4 раза (было 3)

## 📐 Математическое обоснование

### Формула для расстояния шага:

```
Step_Distance = COXA_Amplitude × cos(leg_angle) × step_count
```

**Версия 2.0:**
```
Distance = 100 × cos(0°) × 4 = 400 единиц за цикл
```

**Версия 3.0:**
```
Distance = 180 × cos(0°) × 4 = 720 единиц за цикл
```

**Увеличение:** 720/400 = **1.8x (на 80% быстрее!)**

---

### Прямолинейность движения

Для прямого движения критически важно:

1. **Симметрия траекторий:** TRANSFER и SUPPORT должны быть зеркальны
   - ✅ Версия 3.0: 1320 ↔ 1680 (идеальная симметрия)

2. **Синхронность ног:** Все `LEG_FORWARD_DIRECTIONS = +1`
   - ✅ Версия 3.0: Все ноги двигаются синхронно

3. **Баланс сил:** Сумма векторов всех ног должна быть направлена вперёд
   ```
   Tripod 1: FR(+180) + RR(+180) + ML(+180) = +540 (вперёд!)
   Tripod 2: FL(+180) + RL(+180) + MR(+180) = +540 (вперёд!)
   Результирующий вектор: 0° (прямо!)
   ```
